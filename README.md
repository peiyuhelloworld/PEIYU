# 萧逸 Codex 桌宠备份

这是当前安装版本的萧逸桌宠包，包含桌宠配置和动画贴图，适合重装系统后恢复使用。

## 文件

- `pet.json`：桌宠名称、描述及 v2 贴图配置
- `spritesheet.webp`：桌宠动画贴图

## 重装后恢复

将本仓库中的 `pet.json` 与 `spritesheet.webp` 放入新系统的 `%USERPROFILE%\.codex\pets\xiao-yi\` 文件夹。若 Codex 未自动启用，请在桌宠管理界面重新导入或选择该桌宠。

## 说明

这份备份来自 Codex 当前安装目录。原始制作工作区当前为空，因此此仓库保存的是可安装桌宠文件，不包含未找到的分层绘图文件、源图或动画编辑工程。
